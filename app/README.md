# Omnitask Local

Приватный local-first менеджер задач для Windows и Android (Flutter).
Основан на функционале и оформлении справочного проекта **OmniTask** (`mcp-todo`),
но полностью локальный: без облака, пользователей, аутентификации, вебхуков и MCP.

## Идея

Вы владеете данными: при первом запуске выбираете папку-хранилище (vault),
в которой создаётся один файл SQLite — `tasks.db`. Синхронизируйте папку
любым удобным способом (рекомендуется Syncthing) — приложение просто
читает и пишет файлы.

## Возможности (MVP)

- **Доски** — рабочие пространства со списками, тегами и задачами (как в
  оригинале): создание/переименование/цвет, переключение.
- **Списки-колонки** (Не начато / В работе / Готово / Архив + свои), с
  редактируемым «свойством»: к выполнению / в работе / завершённые.
- **Задачи**: заголовок, описание (Markdown с предпросмотром), даты начала и
  дедлайна, приоритет (низкий/средний/высокий), сумма (доход/расход) с валютой.
- **Канбан с жестами**: свайп карточки вправо/влево переносит задачу в
  следующий/предыдущий список (в крайних списках — удаление с подтверждением).
- **Фильтры-сводка**: Всего / К выполнению / В работе / Готово / Просрочено /
  Запланировано + облако тегов.
- **Блокирующие задачи**: задача не может быть завершена, пока не выполнены
  её блокеры; на карточке — полоса прогресса.
- **Циклические задачи**: период (день/неделя/месяц/год), каждые N периодов,
  окно показа за N дней до дедлайна; кнопки «Выполнено/Пропустить/
  Остановить/История».
- **Валюты**: код, название, символ, курс к USD.
- **История изменений**: даты, приоритет, сумма, статус — в карточке задачи.
- **Локальные уведомления** о дедлайнах (24 часа / просрочка), настраиваются
  в настройках.

## Технологии

- Flutter 3.24+ (Dart), Material 3.
- `sqlite3` + `sqlite3_flutter_libs` — прямой SQLite в папке хранилища.
- `flutter_local_notifications` (Android), `local_notifier` (Windows).
- `provider` — состояние, `file_selector` — выбор папки.

## Структура

```
lib/
  models.dart          # доменные модели (доски, списки, задачи, теги, валюты…)
  vault.dart           # слой хранения: SQLite-схема, миграции, бизнес-логика
  app_controller.dart  # ChangeNotifier: состояние доски, фильтры, операции
  app_config.dart      # путь к хранилищу (вне vault)
  notifications.dart   # локальные уведомления о дедлайнах
  main.dart            # bootstrap: онбординг или главный экран
  ui/
    theme.dart         # цвета/палитры в стиле справочного проекта
    onboarding_screen.dart
    home_screen.dart   # сводка, теги, группы списков
    task_card.dart     # карточка со свайпами, блокерами, циклами
    task_form_dialog.dart  # редактор задачи
    dialogs.dart       # доски, списки, валюты, настройки, «О программе»
```

## Запуск и тесты

```bash
# Linux-тесты требуют libsqlite3.so (в Debian/Ubuntu: apt install libsqlite3-dev)
flutter test

# Windows
flutter build windows --release

# Android (на машине с Android SDK)
flutter build apk --release
```
